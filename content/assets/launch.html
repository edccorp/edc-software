Install once, in Blender

Add the EDC Software repository and every product — free or paid — installs from Get Extensions and updates automatically.

Repository URL https://extensions.edccorp.com/index.json
  1. Edit › Preferences › Get Extensions. Open the Repositories dropdown › + › Add Remote Repository, and paste the URL above.
  2. Tick “Requires Access Token” and paste your token into the Secret field. Free tools issue a token instantly after a quick sign-up.
  3. Install your products from the Available list.
  4. Enable the add-on and Save Preferences so it stays active next time you open Blender.

Lost your token, or setting up a new computer? Have it emailed to you — it goes to the address on your account.

Already have an older CamMatch or HVE Menu installed the old way? You can disable or remove it anytime from Edit › Preferences › Add-ons — search for it, untick it to disable, or use Remove to uninstall. The new extension replaces it.
